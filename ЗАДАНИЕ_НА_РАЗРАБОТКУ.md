# ЗАДАНИЕ НА РАЗРАБОТКУ ПРОГРАММНОГО ОБЕСПЕЧЕНИЯ

## Проект: CMDocumentRepository

### Назначение системы
Корпоративная система электронного документооборота для хранения, версионирования, согласования и управления документами с поддержкой групповой работы.

---

## ТЕХНОЛОГИЧЕСКИЙ СТЕК

| Компонент | Технология |
|-----------|-----------|
| Платформа | .NET 8 / ASP.NET Core MVC |
| Архитектура | Clean Architecture (Domain, Application, Infrastructure, Presentation) |
| ORM | Entity Framework Core 8 |
| БД | PostgreSQL 15+ (хост: 192.168.19.129) |
| Аутентификация | JWT (access + refresh токены) |

| Диаграммы | Chart.js / D3.js, Gantt-библиотека |
| Логирование | Serilog |
| Фоновые задачи | Hangfire |
| CQRS | MediatR |
| Валидация | FluentValidation |
| Маппинг | AutoMapper |

## ФУНКЦИОНАЛЬНЫЕ МОДУЛИ

### Модуль 1: Аутентификация и авторизация
- JWT токены (access: 15 мин, refresh: 7 дней)
- Хранение refresh токенов в БД
- Автоматическое обновление токенов
- Блокировка после 5 неудачных попыток (15 мин)
- Роли: SuperAdmin, Admin, Manager, User, Auditor, Guest
- Создание суперпользователя `su` / `1234567890` при первом запуске

### Модуль 2: Управление пользователями
- CRUD пользователей
- Назначение/изменение ролей
- Сброс пароля
- Блокировка/разблокировка
- Просмотр активности

### Модуль 3: Управление документами
- Структура: номер, название, описание, тип, категория, версия, статус, метаданные
- Типы: Договоры, Приказы, Акты, Счета, Накладные, Тех.документация, Протоколы, Отчеты
- Категории: Финансовые, Юридические, Кадровые, Технические, Административные, Маркетинговые
- Автоматическая нумерация: `{префикс}-{год}-{порядковый номер}`
- Версионность: история изменений, восстановление, сравнение версий
- Жизненный цикл: Черновик → На согласовании → Согласован → Действует → Архив
- Сроки актуальности с уведомлениями (за 7, 3, 1 день)

### Модуль 4: Хранение файлов
- Файлы в файловой системе: `{GUID}_{ОригинальноеИмя}`
- Версии в папке `{имя_файла}.history/`
- Макс. размер: 50 МБ
- Разрешенные: .pdf, .doc, .docx, .xls, .xlsx, .txt, .jpg, .png
- Запрещенные: .exe, .bat, .cmd, .com, .ps1, .vbs, .js, .jar, .app, .dmg, .msi, .sh
- Санитизация имени файла

### Модуль 5: Согласование документов
- Последовательное, параллельное, смешанное согласование
- Статусы: Pending, Approved, Rejected, Rework
- Комментарии при отклонении
- Уведомления согласующим

### Модуль 6: Kanban-доска
- Столбцы: Backlog → In Progress → Review → Done
- Drag-and-drop
- Приоритеты: Low, Medium, High, Critical
- Фильтрация, подзадачи, вложения

### Модуль 7: Диаграмма Ганта
- Визуализация задач на временной шкале
- Связи между задачами
- Экспорт в PNG/PDF

### Модуль 8: Поиск
- Полнотекстовый поиск (PostgreSQL FTS)
- Фильтры: тип, категория, дата, статус, автор, номер
- Поиск по MetaInfo (JSONB)

### Модуль 9: Уведомления по email
- Шаблоны писем
- Список рассылки
- Уведомления о согласовании, сроках, изменениях

### Модуль 10: Администрирование
- Управление пользователями и ролями
- Справочники (типы, категории)
- Аудит-логи
- Настройки системы

### Модуль 11: UI/UX
- Адаптивный дизайн (Bootstrap 5)
- Светлая/темная темы (localStorage)
- Левое вертикальное меню (сворачиваемое)
- DataTables, модальные окна, Toast уведомления
- Загрузка файлов с прогресс-баром

## ТРЕБОВАНИЯ К БЕЗОПАСНОСТИ
- XSS, CSRF защита
- SQL Injection (EF Core параметризация)
- Rate Limiting
- CORS, HTTPS
- Пароли: BCrypt
- JWT: HMACSHA256
- Мягкое удаление документов (IsDeleted = true, корзина 30 дней)

- Интеграционные тесты
- Время загрузки страницы < 2 сек
