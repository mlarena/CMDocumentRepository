# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## на разработку корпоративной системы управления документами (СЭД)

### 1. ОБЩИЕ СВЕДЕНИЯ

#### 1.1 Назначение системы
Разработка корпоративной системы электронного документооборота для хранения, версионирования, согласования и управления документами с поддержкой групповой работы.

#### 1.2 Цели создания
- Централизованное хранение документов с версионностью
- Автоматизация процессов согласования
- Управление жизненным циклом документов
- Повышение прозрачности документооборота
- Интеграция с существующими бизнес-процессами

#### 1.3 Требования к системе
- Веб-приложение на ASP.NET Core MVC
- Чистая архитектура (Clean Architecture)
- СУБД PostgreSQL
- JWT-аутентификация
- Ролевая модель авторизации

### 3. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

#### 3.1 Аутентификация и авторизация

**3.1.1 Аутентификация**
- JWT токены (access + refresh токены)
- Время жизни токена: 15 минут (access), 7 дней (refresh)
- Хранение refresh токенов в базе данных
- Автоматическое обновление токенов
- Вход/выход из системы
- Блокировка после 5 неудачных попыток (на 15 минут)

**3.1.2 Ролевая модель**
```
- SuperAdmin (полный доступ, создается по умолчанию)
- Admin (управление пользователями, настройки системы)
- Manager (создание документов, согласование)
- User (просмотр, создание документов)
- Auditor (только просмотр)
- Guest (ограниченный просмотр)
```

**3.1.3 Права доступа (CRUD)**
| Роль | Создание | Чтение | Обновление | Удаление | Согласование |
|------|----------|--------|------------|----------|--------------|
| SuperAdmin | ✓ | ✓ | ✓ | ✓ | ✓ |
| Admin | ✓ | ✓ | ✓ | - | - |
| Manager | ✓ | ✓ | ✓ | - | ✓ |
| User | ✓ | ✓ | - | - | - |
| Auditor | - | ✓ | - | - | - |
| Guest | - | limited | - | - | - |

#### 3.5 Согласование документов

**3.5.1 Процесс согласования**
1. Пользователь создает документ
2. Отправляет на согласование выбранным пользователям
3. Согласующие получают уведомления
4. Каждый согласующий может:
   - Согласовать
   - Отклонить (с комментарием)
   - Запросить доработку
5. При согласовании всеми пользователями документ переходит в статус "Согласован"
6. При отклонении - в статус "Отклонен" с комментарием
7. При запросе доработки - в статус "На доработке"

**3.5.2 Настройка маршрутов согласования**
- Последовательное согласование
- Параллельное согласование
- Смешанное (параллельно-последовательное)
- Назначение заменяющих лиц

### 5. БАЗА ДАННЫХ

#### 5.1 Схема базы данных

```sql
-- Пользователи
CREATE TABLE Users (
    Id UUID PRIMARY KEY,
    UserName VARCHAR(100) UNIQUE NOT NULL,
    Email VARCHAR(255) UNIQUE NOT NULL,
    PasswordHash VARCHAR(255) NOT NULL,
    FirstName VARCHAR(100),
    LastName VARCHAR(100),
    MiddleName VARCHAR(100),
    Role VARCHAR(50) NOT NULL,
    IsActive BOOLEAN DEFAULT TRUE,
    IsLocked BOOLEAN DEFAULT FALSE,
    LockedUntil TIMESTAMP,
    CreatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt TIMESTAMP,
    LastLoginAt TIMESTAMP,
    RefreshToken VARCHAR(255),
    RefreshTokenExpiry TIMESTAMP
);

-- Типы документов
CREATE TABLE DocumentTypes (
    Id UUID PRIMARY KEY,
    Name VARCHAR(100) NOT NULL,
    Code VARCHAR(50) UNIQUE NOT NULL,
    Description TEXT,
    IsSystem BOOLEAN DEFAULT FALSE,
    CreatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Категории документов
CREATE TABLE Categories (
    Id UUID PRIMARY KEY,
    Name VARCHAR(100) NOT NULL,
    Code VARCHAR(50) UNIQUE NOT NULL,
    Description TEXT,
    ParentCategoryId UUID REFERENCES Categories(Id),
    CreatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Документы
CREATE TABLE Documents (
    Id UUID PRIMARY KEY,
    DocumentNumber VARCHAR(50) UNIQUE NOT NULL,
    Title VARCHAR(500) NOT NULL,
    Description TEXT,
    CategoryId UUID REFERENCES Categories(Id),
    DocumentTypeId UUID REFERENCES DocumentTypes(Id),
    Version INTEGER DEFAULT 1,
    Status VARCHAR(50) DEFAULT 'Draft',
    CreatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt TIMESTAMP,
    CreatedBy UUID REFERENCES Users(Id),
    UpdatedBy UUID REFERENCES Users(Id),
    ApprovedBy UUID REFERENCES Users(Id),
    ApprovedAt TIMESTAMP,
    ValidFrom TIMESTAMP,
    ValidUntil TIMESTAMP,
    FilePath VARCHAR(500),
    FileSize BIGINT,
    FileExtension VARCHAR(10),
    MimeType VARCHAR(100),
    IsDeleted BOOLEAN DEFAULT FALSE,
    DeletedAt TIMESTAMP,
    DeletedBy UUID REFERENCES Users(Id),
    Metadata JSONB,
    SearchVector TSVECTOR
);

-- Версии документов
CREATE TABLE DocumentVersions (
    Id UUID PRIMARY KEY,
    DocumentId UUID REFERENCES Documents(Id) ON DELETE CASCADE,
    VersionNumber INTEGER NOT NULL,
    FilePath VARCHAR(500) NOT NULL,
    FileSize BIGINT,
    CreatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CreatedBy UUID REFERENCES Users(Id),
    ChangeComment TEXT,
    UNIQUE(DocumentId, VersionNumber)
);

-- Согласование
CREATE TABLE Approvals (
    Id UUID PRIMARY KEY,
    DocumentId UUID REFERENCES Documents(Id) ON DELETE CASCADE,
    ApproverId UUID REFERENCES Users(Id),
    Status VARCHAR(50) DEFAULT 'Pending',
    Comment TEXT,
    OrderNumber INTEGER,
    CreatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt TIMESTAMP,
    UNIQUE(DocumentId, ApproverId)
);

-- Задачи (Kanban)
CREATE TABLE Tasks (
    Id UUID PRIMARY KEY,
    Title VARCHAR(500) NOT NULL,
    Description TEXT,
    Priority VARCHAR(20) DEFAULT 'Medium',
    Status VARCHAR(50) DEFAULT 'Backlog',
    AssigneeId UUID REFERENCES Users(Id),
    ProjectId UUID,
    DueDate TIMESTAMP,
    CreatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt TIMESTAMP,
    CreatedBy UUID REFERENCES Users(Id),
    OrderNumber INTEGER
);

-- История изменений
CREATE TABLE AuditLogs (
    Id UUID PRIMARY KEY,
    UserId UUID REFERENCES Users(Id),
    Action VARCHAR(50) NOT NULL,
    EntityType VARCHAR(50) NOT NULL,
    EntityId UUID,
    OldValues JSONB,
    NewValues JSONB,
    CreatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Настройки системы
CREATE TABLE SystemSettings (
    Id UUID PRIMARY KEY,
    Key VARCHAR(100) UNIQUE NOT NULL,
    Value TEXT,
    Description TEXT,
    CreatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt TIMESTAMP
);

-- Индексы
CREATE INDEX idx_documents_status ON Documents(Status);
CREATE INDEX idx_documents_category ON Documents(CategoryId);
CREATE INDEX idx_documents_type ON Documents(DocumentTypeId);
CREATE INDEX idx_documents_createdby ON Documents(CreatedBy);
CREATE INDEX idx_documents_validfrom ON Documents(ValidFrom);
CREATE INDEX idx_documents_validuntil ON Documents(ValidUntil);
CREATE INDEX idx_documents_metadata ON Documents USING GIN (Metadata);
CREATE INDEX idx_documents_search ON Documents USING GIN (SearchVector);
```

### 6. БЕЗОПАСНОСТЬ

#### 6.1 Защита от уязвимостей
- XSS защита (анти-XSS фильтры)
- CSRF защита (антифорговые токены)
- SQL Injection (EF Core параметризация)
- Rate Limiting (ограничение запросов)
- CORS настройки
- HTTPS принудительно

#### 6.2 JWT настройки
```csharp
services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options => {
        options.TokenValidationParameters = new TokenValidationParameters {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,
            ValidIssuer = Configuration["Jwt:Issuer"],
            ValidAudience = Configuration["Jwt:Audience"],
            IssuerSigningKey = new SymmetricSecurityKey(
                Encoding.UTF8.GetBytes(Configuration["Jwt:Key"])
            )
        };
    });
```

#### 6.3 Шифрование
- Пароли: BCrypt (или PBKDF2)
- JWT: HMACSHA256
- Данные в транзите: TLS 1.2+

#### 6.4 Защита документов от удаления
- Мягкое удаление (IsDeleted = true)
- Хранение в корзине 30 дней
- Восстановление из корзины
- Полное удаление только администратором

### 7. РАЗВЕРТЫВАНИЕ

#### 7.1 Bash-скрипты для Debian

**install.sh**
```bash
#!/bin/bash
# Установка зависимостей
apt-get update
apt-get install -y dotnet-sdk-8.0 postgresql nginx

# Создание БД
sudo -u postgres psql -c "CREATE DATABASE documentdb;"
sudo -u postgres psql -c "CREATE USER docuser WITH PASSWORD 'password';"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE documentdb TO docuser;"

# Сборка проекта
dotnet publish -c Release -o /var/www/document-system

# Настройка службы systemd
cp document-system.service /etc/systemd/system/
systemctl enable document-system
systemctl start document-system

# Настройка nginx
cp nginx.conf /etc/nginx/sites-available/document-system
ln -s /etc/nginx/sites-available/document-system /etc/nginx/sites-enabled/
systemctl reload nginx
```

**update.sh**
```bash
#!/bin/bash
# Обновление системы
systemctl stop document-system
git pull origin main
dotnet publish -c Release -o /var/www/document-system
systemctl start document-system
```

**backup.sh**
```bash
#!/bin/bash
# Резервное копирование
BACKUP_DIR="/backups/$(date +%Y%m%d)"
mkdir -p $BACKUP_DIR

# Бэкап БД
pg_dump documentdb > $BACKUP_DIR/documentdb.sql

# Бэкап файлов
tar -czf $BACKUP_DIR/uploads.tar.gz /uploads/

# Очистка старых бэкапов (7 дней)
find /backups -type d -mtime +7 -exec rm -rf {} \;
```
