## Команды для запуска

```bash
# Восстановление пакетов
dotnet restore

# Сборка
dotnet build

# Создание миграции
dotnet ef migrations add Name --project CMDocumentRepository.Infrastructure --startup-project CMDocumentRepository.Presentation

# Применение миграций
dotnet ef database update --project CMDocumentRepository.Infrastructure --startup-project CMDocumentRepository.Presentation

# Запуск тестов
dotnet test

# Запуск приложения
dotnet run --project CMDocumentRepository.Presentation --urls "http://localhost:5000"
```

## Проблемы и решения

### AutoMapper 14.0.0 уязвимость
Известная уязвимость GHSA-rvv3-g6hj-g44x. Можно обновить когда выйдет патч.

### EF Core tools version
Версия tools 10.0.9 старше runtime 10.0.10. Обновите: `dotnet tool update --global dotnet-ef`
