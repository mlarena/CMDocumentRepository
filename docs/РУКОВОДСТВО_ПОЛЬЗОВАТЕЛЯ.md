# Руководство пользователя CMDocumentRepository

## Введение

CMDocumentRepository — корпоративная система управления документами для хранения, версионирования, согласования и совместной работы с документами.

## Вход в систему

1. Откройте адрес системы в браузере
2. Введите имя пользователя и пароль
3. Нажмите "Войти"

### Учётные записи по умолчанию

| Пользователь | Пароль | Роль |
|--------------|--------|------|
| su | 1234567890 | Суперадминистратор |

## Работа с документами

### Создание документа

1. Перейдите в раздел "Документы"
2. Нажмите "Создать документ"
3. Заполните обязательные поля:
   - Название документа
   - Тип документа
   - Категория
4. При необходимости загрузите файл
5. Укажите сроки действия
6. Нажмите "Создать"

### Просмотр документов

- "Все документы" — полный список
- "Мои документы" — документы, созданные вами
- "На согласовании" — документы, ожидающие вашего согласования
- "Корзина" — удалённые документы

### Редактирование документа

1. Откройте документ
2. Нажмите "Редактировать"
3. Внесите изменения
4. При загрузке нового файла автоматически создаётся новая версия

### Версионность

Система использует схему версионирования как в SharePoint:
- Основные версии: 1.0, 2.0, 3.0
- Промежуточные версии: 1.1, 1.2, 2.1

При загрузке файла с тем же названием автоматически создаётся минорная версия.

### Удаление и восстановление

- Удалённые документы перемещаются в корзину на 30 дней
- Из корзины можно восстановить документ
- Полное удаление доступно только администратору

## Согласование документов

### Отправка на согласование

1. Откройте документ в статусе "Черновик" или "На доработке"
2. Нажмите "Отправить на согласование"
3. Выберите согласующих
4. Документ будет отправлен выбранным пользователям

### Согласование

1. Перейдите в раздел "Согласование"
2. Откройте документ для согласования
3. Выберите действие:
   - **Согласовать** — документ переходит в статус "Согласован"
   - **Отклонить** — документ возвращается автору с комментарием
   - **Запросить доработку** — документ возвращается на доработку

## Kanban-доска

Kanban-доска позволяет управлять задачами с помощью перетаскивания карточек между столбцами:

- **Backlog** — задачи в очереди
- **In Progress** — задачи в работе
- **Review** — задачи на проверке
- **Done** — завершённые задачи

### Создание задачи

1. На Kanban-доске нажмите "Новая задача"
2. Заполните название и описание
3. Укажите приоритет и исполнителя
4. Сохраните

### Перемещение задачи

Перетащите карточку задачи из одного столбца в другой.

## Поиск документов

1. Перейдите в раздел "Поиск"
2. Введите ключевое слово
3. При необходимости используйте фильтры:
   - Тип документа
   - Категория
   - Статус
   - Период дат

## Администрирование

### Управление пользователями

Только для ролей SuperAdmin и Admin:

1. Перейдите в "Администрирование" -> "Пользователи"
2. Создайте, редактируйте или удалите пользователей
3. Назначайте роли и блокируйте учётные записи

### Управление справочниками

- **Типы документов** — добавляйте и редактируйте типы (Договор, Приказ и т.д.)
- **Категории** — управляйте категориями документов

### Права доступа

Администратор может назначать права на конкретные документы:
- Чтение
- Редактирование
- Согласование
- Удаление

Для переключения между светлой и тёмной темой используйте переключатель в интерфейсе.
