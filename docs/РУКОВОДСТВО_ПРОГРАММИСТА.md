# Руководство программиста CMDocumentRepository

## Архитектура проекта

Проект построен по принципам Clean Architecture с четырьмя слоями:

```
CMDocumentRepository/
├── CMDocumentRepository.Domain/           # Ядро: сущности, интерфейсы
├── CMDocumentRepository.Application/      # Use Cases, DTO, CQRS
├── CMDocumentRepository.Infrastructure/   # Репозитории, DbContext, сервисы
├── CMDocumentRepository.Presentation/     # MVC контроллеры, Views
└── CMDocumentRepository.Tests/            # Unit тесты
```

## Технологический стек

| Компонент | Технология |
|-----------|-----------|
| Платформа | .NET 10 |
| ORM | Entity Framework Core 10 |
| БД | PostgreSQL |
| Аутентификация | Cookie-based |
| Паттерны | CQRS (MediatR), Repository |

## CQRS команды

### Документы

- `CreateDocumentCommand` — создание документа
- `UpdateDocumentCommand` — обновление документа (создание новой версии)
- `DeleteDocumentCommand` — мягкое удаление
- `RestoreDocumentCommand` — восстановление из корзины
- `SetDocumentStatusCommand` — изменение статуса

### Пользователи

- `CreateUserCommand` — создание пользователя
- `UpdateUserCommand` — обновление данных
- `DeleteUserCommand` — удаление
- `ToggleUserLockCommand` — блокировка/разблокировка

### Согласование

- `SendForApprovalCommand` — отправка на согласование
- `ApproveDocumentCommand` — согласование
- `RejectDocumentCommand` — отклонение
- `RequestReworkCommand` — запрос доработки

### Задачи

- `CreateTaskCommand` — создание задачи
- `UpdateTaskCommand` — обновление
- `MoveTaskCommand` — перемещение на Kanban

## Добавление новой сущности

1. Создайте сущность в `Domain/Entities/`
2. Создайте enum в `Domain/Enums/` (если нужен)
3. Создайте интерфейс репозитория в `Domain/Interfaces/`
4. Создайте конфигурацию в `Infrastructure/Configurations/`
5. Добавьте DbSet в `AppDbContext`
6. Реализуйте репозиторий в `Infrastructure/Repositories/`
7. Создайте DTO в `Application/DTOs/`
8. Создайте команды/запросы в `Application/Commands/` и `Application/Queries/`
9. Создайте обработчики
10. Создайте валидатор в `Application/Validators/`
11. Создайте контроллер в `Presentation/Controllers/`
12. Создайте представления в `Presentation/Views/`

## Добавление нового контроллера

```csharp
[Authorize]
public class MyController : Controller
{
    private readonly IMediator _mediator;

    public MyController(IMediator mediator)
    {
        _mediator = mediator;
    }

    public async Task<IActionResult> Index()
    {
        var result = await _mediator.Send(new GetAllMyQuery());
        return View(result);
    }
}
```

## Валидация

Используйте FluentValidation:

```csharp
public class MyCommandValidator : AbstractValidator<MyCommand>
{
    public MyCommandValidator()
    {
        RuleFor(x => x.Name)
            .NotEmpty().WithMessage("Название обязательно")
            .MaximumLength(100).WithMessage("Максимум 100 символов");
    }
}
```
