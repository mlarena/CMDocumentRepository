# Управление процессами dotnet

## Остановка процессов

### PowerShell - убить все dotnet процессы
```powershell
Get-Process -Name dotnet -ErrorAction SilentlyContinue | Stop-Process -Force
```

### PowerShell - найти процесс по порту и убить
```powershell
# Найти процесс слушающий порт 6200
Get-NetTCPConnection -LocalPort 6200 -ErrorAction SilentlyContinue | Select-Object OwningProcess | ForEach-Object { Get-Process -Id $_.OwningProcess }

# Убить процесс по порту
Get-NetTCPConnection -LocalPort 6200 -ErrorAction SilentlyContinue | Select-Object -Unique OwningProcess | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

### PowerShell - найти все dotnet процессы
```powershell
Get-Process -Name dotnet | Select-Object Id, ProcessName, StartTime
```

### PowerShell - проверить свободен ли порт
```powershell
Test-NetConnection -ComputerName localhost -Port 6200 -InformationLevel Quiet
```

### CMD - убить процесс по имени
```cmd
taskkill /F /IM dotnet.exe
```

### CMD - найти процесс по порту
```cmd
netstat -ano | findstr :6200
```
