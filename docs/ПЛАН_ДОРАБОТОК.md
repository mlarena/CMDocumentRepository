- [ ] Разделить на отдельные файлы по доменам:

  - `ApprovalQueryHandlers.cs`
  - `TaskQueryHandlers.cs`
  - `ReferenceQueryHandlers.cs`
  - `DashboardQueryHandlers.cs`
- **Сейчас:** 850 строк, 25 handler-классов в одном файле

- [ ] В `GetAllDocumentsQueryHandler`, `SearchDocumentsQueryHandler`, `GetPagedDocumentsQueryHandler` — заменить `foreach` с отдельными запросами на `Include()`/`Join()`
- [ ] Использовать `.Include(d => d.Category).Include(d => d.DocumentType).Include(d => d.Creator)` в репозитории

- **Требует решения:** Cookie auth для MVC — нормальная практика

### 2.4 Unit of Work / транзакции
